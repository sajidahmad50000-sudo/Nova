# Nova

Nova ek awaaz se chalne wala Android assistant hai (Roman Urdu, Urdu aur English).

"Nova" kahein, wo jawab de: "Ji, main yahan hoon. Bataiye Boss, kya karna hai?"
Phir hukm dein, jaise "Sajid ko message karo main late aaunga".

## Kya kar sakta hai
- WhatsApp message bhejna (tasdeeq ke baad, Send khud dabata hai)
- Call, alarm, timer, torch, awaaz kam zyada
- Koi bhi app kholna, YouTube / Google / Map search
- Waqt, tareekh, latifa
- Smart mode (Claude AI), natural cloud awaaz, asli wake word (ikhtiyari)

## Chalane ke liye
1. `nova-android.zip` extract karein.
2. Android Studio mein `nova-android` folder Open karein.
3. Phone jor kar Run dabayein.
4. Poori hidayat andar `README.md` mein hain.
